# Bundled UI assets

`ui_assets.zip` contains unmodified offline UI resources:

- `fonts/Pretendard-Regular.otf` and `fonts/Pretendard-Bold.otf`: Pretendard 1.3.9 by Kil Hyung-jin. Licensed under SIL Open Font License 1.1; the full original license and copyright notice are included as `fonts/OFL.txt`. Source: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- `portraits/*.png`: 173 champion icons from Riot Games Data Dragon 16.18.1. © Riot Games. Source: https://ddragon.leagueoflegends.com/cdn/16.18.1/img/champion/ and https://developer.riotgames.com/docs/lol#data-dragon

The font is registered privately for this process on Windows; it is not installed system-wide. Portraits are used for champion identification in this unofficial fan-made helper. The application is not endorsed by Riot Games.

Visual reference: the clear action hierarchy and panel separation in Riot's VALORANT interface update, adapted to the existing League-inspired navy, gold and cyan palette: https://playvalorant.com/en-gb/news/game-updates/preview-the-future-of-valorant-s-interface/
